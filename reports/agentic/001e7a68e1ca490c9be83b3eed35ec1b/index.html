【優先1：SQL Server／データベース基盤】
・対象：CVE-2019-1068、Microsoft SQL Server
・CISA事実：Database EngineサービスアカウントのコンテキストでRCE可能。RansomwareはUnknown、dueDateは2026-08-29。
・分析：勘定・顧客・取引関連など重要データを扱うDBや、その接続先・バッチ基盤に波及し得る一般的な業務機能上の重要度が高い。金融機関での実利用や侵害は未確認。
・監査質問／証跡：
- SQL Serverの全インスタンス、バージョン、所有部署、業務重要度は資産台帳に網羅されているか（台帳、構成管理、CMDB）。
- 外部公開、接続元ネットワーク、管理ポート、委託先接続は特定・承認されているか（FWルール、公開診断、接続申請）。
- CISA期限を踏まえたパッチ適用または緩和策の実施状況・検証結果はあるか（変更記録、適用ログ、脆弱性スキャン）。
- 未対応の場合、期限、代替統制、責任者、承認済み例外は記録されているか（例外台帳、リスク受容記録）。
- 運用・ホスティング委託先の対象資産と対応完了証跡を回収しているか（契約、報告書、作業証明）。

・分析：文書・申請書・顧客資料等を扱うファイル共有機能との関連が想定され、機密性・完全性の確認を優先。金融機関での実利用・侵害は断定不可。
・監査質問／証跡：
